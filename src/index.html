How the sentence is built

Refresh the page. Each excuse is one item from each list, joined in this order.

  1. Who: The dog, My grandma, The mailman, My bird.
  2. Action: ate, peed, crushed, broke.
  3. What: my homework, my phone, the car.
  4. When: before the class, when I was sleeping, while I was exercising, during my lunch, while I was praying.
